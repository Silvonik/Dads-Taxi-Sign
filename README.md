# Dads-Taxi-Sign
![Car](https://github.com/Silvonik/Dads-Taxi-Sign/blob/main/assets/1.jpg)
A 3D printed sign for my dad's taxi because there has been some recent activity in my area where people are smashing taxis for cash.

I used Fusion 360 to make the design, then I used Orca Slicer to slice the design and get its Gcode to print on my Centauri Carbon 2.

![Window](https://github.com/Silvonik/Dads-Taxi-Sign/blob/main/assets/2.jpg)
I'm very happy of how it turned out and it works perfectly on my dads taxi!
